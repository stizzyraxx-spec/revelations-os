Privacy
Policy.

Proverbs is a local tool. The short version: when you use a local model, zero bytes of your code, prompts, or files ever leave your machine. This document explains what we do and do not store, in plain English.

Effective: June 1, 2026  ·  Company: RAXX BEATS STUDIOS LLC

Privacy at a Glance

📋 What you need to know before reading the full policy
✅
Local models = zero data transmission. When using Ollama (the default), your prompts, code, and files never leave your machine. Inference is local-only.
✅
No telemetry, ever. Proverbs collects no usage analytics, no crash reports, no model metrics. There is no phone-home behavior of any kind.

🌐
This website uses no tracking. proverbscode.com has no analytics, no cookies, no fingerprinting, and no third-party scripts.

We collect nothing. Proverbs has no server-side component for the core product. There is no registration, no account creation, no login, and no telemetry endpoint. RAXX BEATS STUDIOS LLC has no infrastructure that receives data from running instances of Proverbs.

3. What Is Stored Locally

Proverbs writes files to ~/.proverbs/ on your local machine. You own these files completely. You can inspect, edit, or delete them at any time. No part of this directory is transmitted to Proverbs servers (which do not exist).

Location Contents Purpose Ever Transmitted?
~/.proverbs/config.json Active model, backend, theme, feature flags, cloud API keys (if set) Runtime configuration Never (local only)
~/.proverbs/sessions/ Saved conversation history (/save command). JSON files containing message turns. Session persistence and /resume Never (local only)
~/.proverbs/memory.json Persistent facts stored via /memory command. Injected into every session context. Cross-session knowledge Never (local only)
~/.proverbs/knowledge/ Project knowledge base entries from /knowledge and /scan results. Project-aware context injection Never (local only)
~/.proverbs/index/ Vector embeddings generated by /index and /embed. FAISS-format binary files. Semantic search (/semrag) Never (local only)
~/.proverbs/backups/ Automatic file backups before every write. Used by /undo to restore originals. Undo / disaster recovery Never (local only)
~/.proverbs/plugins/ User-installed plugin .js files. Provided by the user, not Proverbs. Plugin execution Never (local only)
<project>/.script Project-specific rules, conventions, and architecture notes written by the user. Persistent per-project context Never (local only)
Ollama model cache GGUF model weight files. Managed by Ollama, stored in the Ollama default directory. Local inference Never (local only)

To delete all Proverbs data: remove the ~/.proverbs/ directory entirely. This removes all sessions, config, memory, index, backups, and knowledge. Proverbs will re-create defaults on next launch. To also remove model weights, follow Ollama's uninstall instructions.

// §4

4. Cloud Fallback Disclosure

Proverbs includes an optional cloud inference fallback feature, accessible via the /fallback and /route commands. This feature is disabled by default.

// How it works

When you enable cloud fallback and configure a third-party API key (e.g., OpenAI or Anthropic), Proverbs sends your prompts directly to that provider's API over HTTPS using the API key you supply. RAXX BEATS STUDIOS LLC is not an intermediary — the request goes from your machine directly to the provider's endpoint.

// What this means for your data

  • Your prompts and any injected file content go to the third-party provider.
  • That data is governed entirely by the provider's own privacy policy — not this one.
  • RAXX BEATS STUDIOS LLC never receives, logs, or processes cloud fallback requests.
  • Your API key is stored in ~/.proverbs/config.json locally. We never see it.

// Relevant third-party policies

  • OpenAI: openai.com/policies/privacy-policy
  • Anthropic (Claude): anthropic.com/privacy
  • LiteLLM (self-hosted proxy): Privacy depends on where you host it. If self-hosted, no third party receives the data.

Recommendation: If your code is sensitive (proprietary, confidential, regulated), keep cloud fallback disabled and use local models only. The default local-only configuration is the privacy-correct choice for sensitive codebases.

7. GDPR & CCPA Compliance

// GDPR (European Union / EEA)

Because Proverbs collects no personal data from users in the normal course of operation, most GDPR obligations do not apply — there is no data to process, no legal basis for processing to declare, and no data controller / processor relationship to establish with respect to your coding activity.

Lawful basis: If you contact us by email, we process your email address under legitimate interest (responding to your inquiry). We retain it only as long as needed to resolve your inquiry and do not add it to any list or database.

// Your GDPR rights

  • Right of access: We hold no profile data about you. If you have emailed us, you may request a copy of that correspondence.
  • Right to erasure: Email us to request deletion of any communication records we hold.
  • Right to portability: All your Proverbs data (sessions, config, knowledge) is already in standard JSON format on your machine — you have it.
  • Right to object: We conduct no automated decision-making or profiling on any user.
  • Right to lodge a complaint: You may lodge a complaint with your local EU supervisory authority.

For all GDPR requests, contact: stizzyraxx@gmail.com

// CCPA (California Residents)

Proverbs does not sell personal information. Proverbs does not share personal information with third parties for cross-context behavioral advertising. We do not collect personal information as defined by the CCPA in the course of normal software operation.

// Your CCPA rights

  • Right to know: We collect no personal information from your use of the software.
  • Right to delete: There is no server-side data to delete. Delete ~/.proverbs/ locally to remove all local data.
  • Right to opt out of sale: We do not sell your data. No opt-out is required.
  • Right to non-discrimination: We do not discriminate based on exercise of CCPA rights.
