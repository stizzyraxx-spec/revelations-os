// What it does

Everything Claude Code does.
Offline. Free. Private.

Its own built-in AI, a browser code editor, project memory that sticks, and 70+ shortcut commands. Drop a model file into ~/.proverbs/models/ and start coding. No external services. No internet required after setup.

🖥️
Browser IDE
VS Code-style interface in your browser — file explorer, tabbed editor, integrated smart terminal, git status panel. Launch with /ide.
🧠
Persistent Project Memory
/remember saves facts about your project permanently. Auto-injected into every session so Proverbs never forgets your stack, conventions, or decisions.
⚡
Near-Instant Repeat Responses
Proverbs remembers the setup it's already seen, so it doesn't redo that work every time — replies start 40–80% faster on follow-up questions.
🎓
Train Your Own AI
Teach Proverbs your own code and style — build and fine-tune your personal model right from the command line. /train tokenizer, /train embed, /train prune.
🎯
Goal Mode
/goal <condition> — Proverbs loops autonomously until the condition is met. Like Claude Code's agentic mode, fully local.
🌐
Run It On Another Computer
Run Proverbs on a spare machine and connect to it over your home network. One script turns a Windows PC into a dedicated coding server, and /backend auto finds it for you.
⚡
Real-time Streaming
Tokens stream to your terminal as they generate. Works in both terminal and browser IDE simultaneously.
🔧
Full Tool Suite
Read, write, patch files. Run bash. Search codebases. Commit to git. Fetch URLs. All tools available to the model automatically.
🔍
Smart Code Search
Search your codebase by meaning, not just exact keywords — Proverbs finds the related code you're actually looking for. Runs entirely on your machine, no outside service.
📋
.script Files
Drop a .script file in any project. Proverbs auto-loads your rules and conventions on every startup and /cwd change.
🔍
Self-Critique Loop
After every code response, the model reviews its own output for bugs and auto-corrects before handing back to you.
📦
Project Intelligence
/scan detects your stack, import aliases, conventions, and git history. Injected into every prompt automatically.
🧩
Plugin System
Drop any .js file in ~/.proverbs/plugins/ to add custom tools the model can call — same interface as built-in tools.
☁️
Claude Cloud Cascade
Run /cloud key to route through Claude (Haiku by default, Opus on demand) for frontier-quality coding — with automatic fallback to your local model when offline. Or set ANTHROPIC_API_KEY/OPENAI_API_KEY directly. You choose: fully local, or cloud-fast.
🧪
Test Runner
Detects jest, vitest, pytest. Runs tests after Proverbs writes code. Feeds failures back for self-correction automatically.
🗺️
Dependency Graph
Builds an import graph. Shows what breaks when you edit a shared file — before you touch it.
💾
Session Branches
/branch saves a named conversation checkpoint. /checkout restores it. Never lose a working state.
↩️
Rewind + Undo
/rewind N rolls back N conversation turns. /undo restores any file write. Full time-travel for both chat and code.
🤖
Multi-Agent Mode
/agents spawns 3 parallel sub-instances each attacking the task from a different angle. /fork runs a sub-task non-blocking.
🔐
Security Auditor
/security runs a full OWASP audit — injection, XSS, hardcoded secrets, missing auth — entirely on local inference. /review high for code review.
🛡️
Sandbox Mode
/sandbox on blocks destructive bash patterns before they reach your shell. Rate limiting, auth middleware, audit log — all built in.
📊
Performance Profiler
/profile shows live latency, tokens/sec, cache hit rate, memory usage, and backend stats. Know exactly what's happening under the hood.
🔄
Self-Update
/update downloads the latest release and hot-swaps itself with zero downtime. No npm, no package manager required.
🌐
No-Key Web Search
Real web results via HTML scraping — DDG then Bing fallback. No API key, no rate limits, results cached locally for 24 hours.

// Get started

Running in under a minute.

One command. The built-in AI starts automatically — just drop a model file into ~/.proverbs/models/ and run proverbs. No external setup.

Terminal
curl -fsSL https://proverbscode.com/install.sh | bash
1
Checks for Node.js 18+ and installs it if missing via Homebrew
2
Starts the built-in Proverbs AI automatically — nothing else to install
3
Downloads a starter model so you can run right away — swap in a different one anytime
4
Installs the proverbs command globally. Run proverbs to chat or proverbs /ide for the browser IDE.
PowerShell (Run as Administrator)
